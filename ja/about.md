# between-essays

## 役割 / Purpose

between-essays は Between の思想的背景と観察を記録するリポジトリです。
ここでは結論を確定するのではなく、問いがどう生まれたか、何に引っかかったかを言葉にします。
このリポジトリは仕様を定義せず、規範も提示しません。
「なぜこの問いが生まれたか」を観察として残すことを優先します。

## 扱う内容 / In Scope

- Between Core に至る思想的文脈

- 観察・気づき・未整理の着想

- Before MSA シリーズ（測定系設計の前段階）

- 既存の設計手法・哲学との接点

- 「こうかもしれない」という可能性の提示


## 扱わない内容 / Out of Scope

- 意味論の厳密定義（→ between-core）

- 形式仕様・スキーマ（→ between-spec）

- 判断基準・読み方ガイド（→ between-docs）

- 実装・デモ・チュートリアル（→ between-labs）

- 効果の保証・推奨の断言


## 書き方の方針 / Writing Policy

このリポジトリでは、文章を観察として扱います。
断言よりも「観察される」「傾向がある」といった記述を優先します。
結論は「可能性」として置き、「かもしれない」「という見方もできる」を基本にします。
前提（文脈・条件・対象範囲）を明示し、一般化しない形で残します。


## 読み方 / How to read

essays は最初に読む必要はありません。
core / docs / labs を使った後に、背景が必要になったときに読むことを想定しています。
未整理のまま残っている文章もありますが、完成度より着眼点の記録を優先しています。

## 他リポジトリとの関係

- between-core
essays が問いを発し、core が形式化します。essays は core を再定義しません。

- between-docs
docs は判断基準を扱い、essays は判断に至る前の観察を扱います。

- between-spec
essays は BSL に依存しません。抽象度の層が異なります。

- between-labs
labs が体験を提供し、essays はその背景を語ることがあります。
